  调 **python**、`_verify_0035` 调 **Chrome**、`_verify_0036~0041` 判据**就是子进程隔离行为**）。

### Fixed（D-145 · 判据文档与实现同步）

  CLI 行为**逐字不变**（仍写默认路径），传自定义路径**真生效**（双向验证：CLI 零回归 + 自定义路径落地）。

### 铁律 33 → 36 条
- **R42**「崩溃态」必须**无条件**映射到既定退出码（`x===null?2:x` 这类**永不成立**的条件会把
  「抛异常」静默降级为「成功」= **假绿**）。
- **R43** 工具/包装器的 CLI 必须**透传被测对象的退出码**（否则调用方取到包装器自身的 rc，**恒 0**）。
- **R44**「消除子进程」**有边界** —— 须先分档（自建子进程 / 判据对象即子进程行为 → **不可**），
  **不可一律推广**。

### 边界声明（本轮据实标注，非缺陷）
- **含异步 I/O 的脚本**（`http`/`fetch`/timer）：vm 同步执行**无法等待异步回调** ⇒ 输出不全
  （实证 `_check_runtime.cjs`）；需在执行器外加「事件循环排空」，本工具**暂不覆盖**。
- **自建子进程的脚本**：沙箱内仍建子进程 ⇒ 仍 EBUSY，同进程化**无用** —— **R36 有边界**。
