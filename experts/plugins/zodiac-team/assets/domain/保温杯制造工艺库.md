## 0. 工艺链全景（从板材到成品）

```
分条下料 → 深冲拉伸(内胆/外壳) → 退火(1050℃) → 水胀成型 → 旋薄/CNC
   → 内胆电解抛光(EP, Ra≤0.4 μm) → 内胆外壁镀铜(磁控溅射反射层)
   → 套装同心 + 放置吸气剂(夹层内) → 激光环焊(杯口密封)
   → 无尾真空钎焊炉(1000℃+, 10⁻³ Pa, 抽真空+烘烤去气+钎焊熔封+吸气剂激活 同一炉完成)
   → 外壳表面处理(喷涂/PVD/丝印/UV/激光蚀刻) 
   → 氦质谱检漏 → 装配(硅胶圈/杯盖) → 测温抽检 → 终包装
```

> ⚠️ 关键工艺顺序说明：
> 1. **电解抛光必须在套装同心之前做**——内胆内壁电解抛光（EP），密封后物理不可达；
> 2. **吸气剂在套装时置入夹层**，在真空炉内与抽真空/钎焊同时完成激活，不是钎焊后单独放置；
> 3. **镀铜反射层在内胆外壁**，套装前镀好，用于减少辐射热损失。**水胀成型与旋薄/CNC 仅在内胆线**（外壳线只有拉伸一道，外壳拉伸后直接进套装同心，两线在套装同心汇合）⇒ 排产时外壳**不得**被送进水胀/旋薄（多余工时＋外壳变形风险）。

参考来源：ESG跨境（2025）、沃泰（2025）、百度百科（无尾真空杯）、米小喜（2025）。

## 1. 成型工艺

### 1.1 深冲拉伸（Deep Drawing）
- 不锈钢板材多次冲压一体成型内胆/外壳，**减少焊缝、提升整体强度**（来源：沃泰，2025）。
- 设备：液压机 **200–400 吨**级（行业通用区间）。
- 配套 **退火 1050℃** 消除加工硬化，恢复塑性。

### 1.2 水胀成型（Hydroforming）
- 利用液体压力使管材/板材贴合模具，制造异形/复杂杯身（来源：沃泰，2025）。
- 优点：消除内应力、提升尺寸精度与一致性、良品率高。
- 米小喜：水胀成型至 **0.4mm** 壁厚（来源：顺企网，2025）。**⚠️ 工序归属（2026-11-20 主理人裁定）：属内胆工序**（外壳线仅拉伸）；依据 `H:\保温杯设计\04_纯钛杯工艺技术.md` L402/L415/L557/L676 + 本文件 §0 主链次序（均在电解抛光之前）。

### 1.3 旋薄 / CNC
- 旋薄（spinning）减薄杯壁、减轻重量；CNC 精修口部与螺纹。
> ⚠️ **工序归属（2026-11-20 主理人裁定）**：水胀成型与旋薄/CNC 属**内胆工序**（外壳线仅拉伸，外壳拉伸后直接进套装同心，两线在套装同心汇合）；依据 `H:\保温杯设计\04_纯钛杯工艺技术.md` L402/L415/L557/L676 + 本文件 §0 主链次序（均在电解抛光之前）

## 2. 真空绝热核心工艺（保温灵魂）

### 2.1 激光环焊（杯口密封）
- 内胆与外壳在杯口处**激光精准密封**，为抽真空创造可靠条件（来源：沃泰，2025）。
- 热影响区小、焊缝美观、强度高。

### 2.2 无尾真空钎焊（Tailless Vacuum Brazing）
> 区分「有尾真空」（底部焊铜管抽气后夹死，易摔破漏气）与「无尾真空」（整体炉抽 + 熔封微孔）。

- 在大型卧式高真空钎焊炉中进行，**工作温度 1000℃ 以上**（来源：ESG跨境/百度百科）。
- 杯底预留微孔，放置**特种铜镍合金钎料 + 助熔剂 / 或玻基钎焊剂（玻璃珠）**。
- 炉内真空度达 **10⁻² – 10⁻³ Pa** 时，钎料熔化，在表面张力与毛细作用下自动流平封死微孔（来源：ESG跨境，2025；今日头条，2025）。
- 米小喜实测：约 **400℃ 高温锁真空、单炉 45 分钟**、智能控压（注：不同炉型工艺窗口不同，400℃ 为其无尾真空一体炉锁真空段，1000℃ 为钎焊熔封段，二者为同线不同工位）。
- 效益：结构一体化、**容积率提升约 20%**、抗跌落几何级增强（来源：ESG跨境，2025）。
- 百度百科：近 1000℃ 抽真空和封焊，回到常温后真空度远高于有尾；采用「熔封技术」保证长期不漏气。

### 2.3 抽真空 + 烘烤去气
- 入炉同时加热烘烤，促使金属表面吸附气体释放。
- 行业高性能目标 **10⁻² – 10⁻³ Pa**（来源：今日头条，2025）。
- **真空不是绝对零空气，而是把气体传热降到可忽略。**

### 2.4 吸气剂（Getter）
- 锆铝/锆钡合金丸，长期吸 residual gas，降低多年使用真空衰减（来源：ESG跨境，2025）。

## 3.5 注塑工艺（杯盖/塑料件主力）

> 杯盖/塑料件是保温杯第二大部件，注塑工艺直接决定手感/密封性/外观。

### 3.5.1 注塑工艺参数（PP/Tritan杯盖）

| 参数 | PP杯盖 | Tritan杯盖 | 说明 |
|---|---|---|---|
| 注塑机吨位 | 80~150吨 | 120~200吨 | 视杯盖大小 |
| 料筒温度 | 180~220℃ | 240~270℃ | Tritan需更高温 |
| 模具温度 | 30~50℃ | 50~70℃ | 模温高→外观好 |
| 注射压力 | 60~100 MPa | 80~120 MPa | |
| 保压压力 | 40~70 MPa | 50~80 MPa | 防缩水关键 |
| 冷却时间 | 15~25秒 | 20~30秒 | |
| 周期时间 | 30~45秒 | 40~60秒 | |

### 3.5.2 常见注塑缺陷与对策

| 缺陷 | 表现 | 原因 | 对策 |
|---|---|---|---|
| 缩水 | 表面凹陷（尤其厚壁处） | 保压不足/料温太高 | 加保压/降模温/加冷却 |
| 飞边 | 分型面溢料 | 锁模力不够/注射压力太高 | 加锁模力/降压力 |
| 熔接痕 | 两股料汇合线 | 料温低/排气差 | 升料温/加排气槽 |
| 翘曲 | 变形不平 | 冷却不均/内应力 | 优化水路/退火处理 |
| 银纹 | 表面银丝 | 原料未干燥/料温太高 | 预干燥/降料温 |
| 气泡 | 内部空洞 | 保压不足/排气差 | 加保压/加排气 |

### 3.5.3 杯盖模具结构要点
- **脱模斜度**：内壁≥1°，外壁≥0.5°，否则顶白/顶穿
- **倒扣处理**：密封圈槽/螺纹用滑块或内螺纹脱模
- **冷却水路**：随形水路最佳，均匀冷却防翘曲
- **进胶点**：潜伏式进胶（自动断料）或热流道（外观好）

## 4.5 常见工艺缺陷与DFMEA（失效模式库）

> 设计评审时必须预判：这个设计在生产中会出什么问题？提前规避。

### 4.5.1 拉伸/冲压工序缺陷

| 失效模式 | 原因 | 后果 | 预防措施 |
|---|---|---|---|
| 起皱 | 压边力不足/拉伸比太大 | 壁厚不均/模具损坏 | 加压力/分多次拉伸 |
| 开裂 | 材料塑性不够/润滑差 | 报废 | 退火/加润滑油/降拉伸速度 |
| 壁厚不均 | 模具间隙不均 | 局部太薄/保温差 | 模具精修/在线测厚 |
| 口部不齐 | 拉伸后切边不准 | 杯盖配不上 | CNC精切/模具定位 |

### 4.5.2 焊接工序缺陷

| 失效模式 | 原因 | 后果 | 预防措施 |
|---|---|---|---|
| 气孔 | 焊缝有油污/保护气不足 | 泄漏/强度低 | 焊前清洗/调保护气 |
| 虚焊 | 激光功率不够/速度太快 | 假焊/漏真空 | 调参数/首件X光检 |
| 烧穿 | 功率太大/速度太慢 | 穿孔/报废 | 降功率/提速度 |
| 热影响区大 | 焊接参数不对 | 变形/晶间腐蚀 | 优化参数/用激光焊 |

### 4.5.3 真空工序缺陷

| 失效模式 | 原因 | 后果 | 预防措施 |
|---|---|---|---|
| 微泄漏 | 焊缝微孔/钎料不足 | 半年后保温失效 | 氦质谱100%检 |
| 真空度不够 | 抽真空时间短/放气多 | 保温差 | 延长烘烤/加吸气剂 |
| 钎焊未熔 | 温度不够/钎料放偏 | 微孔未封死 | 炉温校准/钎料定位 |
| 吸气剂失效 | 激活温度不够/放反 | 长期真空衰减快 | 炉温曲线监控/方向防呆 |

### 4.5.4 表面处理缺陷

| 失效模式 | 原因 | 后果 | 预防措施 |
|---|---|---|---|
| 涂层脱落 | 前处理不干净/附着力差 | 生锈/外观差 | 百格测试/前处理管控 |
| 色差 | 批次/喷涂参数波动 | 同批颜色不一致 | 色差仪管控/首件确认 |
| 桔皮 | 喷涂参数不对 | 表面不光滑 | 调喷枪距离/压力 |
| 流挂 | 喷太厚/距离太近 | 表面流痕 | 控制膜厚/多次薄喷 |

### 4.5.5 注塑工序缺陷

| 失效模式 | 原因 | 后果 | 预防措施 |
|---|---|---|---|
| 密封圈槽尺寸超差 | 模具磨损/收缩率波动 | 漏水/密封差 | 模具定期维护/首件检 |
| 螺纹滑牙 | 脱模斜度不够/材料收缩 | 杯盖拧不紧 | 加脱模斜度/优化保压 |
| 密封圈装反 | 无防呆设计 | 漏水/客诉 | 做非对称槽/方向防呆 |
| 飞边 | 锁模力不够 | 披锋/划手 | 加锁模力/修分型面 |

## 8. 新工艺趋势（2025-2026）

### 8.1 无尾真空普及化
- 原来只有高端杯用无尾真空，现在中端款也开始上

- 表面缺陷从人工目检→机器视觉AI检测
- 良率提升3~5个百分点

### 8.3 个性化定制
- 3D打印杯盖小批量定制（7天→48小时）
- 激光打标个性化刻字
- 小批量定制订单占比从5%→15%

## 9. TRIZ工艺改进矛盾分析（物场模型+76标准解 + 现代TRIZ补充）

> 📚 **TRIZ方法论真源**：`assets/domain/TRIZ方法论速查表.md`（9.1–9.3 经典物场/76标准解供速查；系统级根因走 §9.4 现代路径）
> 🔴 **现代TRIZ口径**：矛盾矩阵是入门级工具；工艺缺陷若反复复发，先做功能分析与因果链定位根因，再用裁剪/物理矛盾分离，勿停留在「挑一个标准解打补丁」。

### 9.1 典型问题：焊接漏气
- **物场模型**：焊料（S2）--热（F）--> 杯壁（S1）
- **问题类型**：效应不足（焊接不牢，漏气）
- **物场类型**：完整但效应不足
- **76标准解应用**：
  - S2.1 转换成复合材料：用更好的焊料（镍基→铜基）
  - S5.1 引入物质：加钎剂，去除氧化膜
  - S5.2 引入场：真空钎焊，无氧化焊接

### 9.2 典型问题：表面处理色差
- **物场模型**：喷涂材料（S2）--压力（F）--> 杯身（S1）
- **问题类型**：有害效应（喷涂不均匀，色差）
- **物场类型**：有害效应
- **76标准解应用**：
  - S1.2 消除有害作用：加静电喷涂，油漆均匀吸附
  - S2.3 向微观级传递：粉末喷涂替代液体喷涂，更均匀
  - S5.1 引入物质：加底漆，提高附着力

### 9.3 典型问题：拉伸开裂
- **物场模型**：模具（S2）--机械力（F）--> 板材（S1）
- **问题类型**：有害效应（拉伸过度，开裂）
- **物场类型**：有害效应
- **76标准解应用**：
  - S1.2 消除有害作用：中间退火，消除加工硬化
  - S2.1 转换成复合材料：用更好拉伸性能的材料
  - S5.2 引入场：加润滑油，减少摩擦

### 9.4 现代路径补充：焊接漏气的因果链与裁剪（2026-11 增补）

9.1 把「焊接漏气」判为"效应不足"后直接选标准解（换焊料/加钎剂/真空钎焊）——这是**症状级**处理，能救急但易复发。现代TRIZ要求先问「为什么效应不足」：

- **功能分析**：焊料的有用功能是"在杯底与杯身之间形成连续气密连接"；不足/有害作用来自氧化膜隔断与热输入不均。
- **因果链**：漏气 ← 焊缝不连续 ← 局部氧化膜未去除 ← 钎剂涂布不均 + 装配间隙波动 ← 人工涂布与夹具定位两道工序引入变异。
- **根因参数**：不是「焊料强度」这类结果参数，而是**涂布一致性 / 装配间隙稳定性**（直接套结果参数即 39 参数层级陷阱）。
- **裁剪（Trimming）**：裁掉「人工涂钎剂」工序，改用自钎焊料或真空钎焊（S5.2 引入场），让气密功能由被保留组件承担 ⇒ 工序减少、理想度提高。
- **物理矛盾分离**：焊接区要高温（熔合）又要低温（不伤真空层与镀铜反射层）→ **空间分离**：局部感应加热焊接区、杯身水冷。

> 判据：同一缺陷在同一工位反复出现时，必须走本节因果链，不得只从 9.1–9.3 挑一个标准解复跑。
