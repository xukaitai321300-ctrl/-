## 0. 核心参数速查（产品图专用）

| 参数 | 推荐值 | 禁止值 | 说明 |
|---|---|---|---|
| **底模** | SDXL 1.0（产品图专用fine-tune版） | Flux（产品图结构控制弱） | 产品图优先SDXL，结构准 |
| **Steps** | **28–36** | 85（过度采样无收益） | SDE采样器需步数收敛保材质 |
| **CFG** | **4.5–6.5** | 8.0+（过平滑=塑料感主因） | 调研铁证：CFG>7就塑料感 |
| **Sampler** | **dpmpp_sde + karras** | Euler a（细节差） | SDE采样器材质表现最好 |
| **Denoise（局部重绘）** | **0.35–0.55** | 0.7+（改局部带坏整张） | 改纹理/颜色用低值，改结构用高值 |
| **Resolution** | **1024×1024 / 1216×832** | 2048×2048（SDXL原生分辨率外） | SDXL原生分辨率最佳 |

## 1. ControlNet 选型指南

> ControlNet是结构控制的核心——没有ControlNet，AI自由发挥就会结构错。

| ControlNet类型 | 控制什么 | 什么时候用 | 推荐权重 |
|---|---|---|---|
| **Depth（深度图）** | 三维结构/透视/体积 | 主图结构控制首选 | 0.7~0.85（⚠️历史记录，已被 2026-11-11 最新指令 0.6~0.8 取代，待本机实跑校准） |
| **Canny（边缘检测）** | 轮廓/线条/细节 | 改纹理/改颜色时锁轮廓 | 0.6~0.75（⚠️历史记录，已被 2026-11-11 最新指令 0.3~0.4 取代，待本机实跑校准） |
| **OpenPose** | 人物姿态 | 有人物的场景图 | 0.5~0.7 |
| **Lineart** | 线稿/产品设计图 | 从草图生成产品图 | 0.7~0.9 |
| **MLSD** | 直线/建筑线条 | 场景/背景控制 | 0.5~0.7 |

### 多ControlNet组合配方
- **产品主图**：Depth(0.8) + Canny(0.6) = 结构准+轮廓清
- **改颜色/纹理**：Canny(0.7) + IP-Adapter(0.5) = 锁轮廓+注材质
- **场景图**：Depth(0.7) + OpenPose(0.5) = 产品结构+人物姿态

## 2. LoRA 调优指南

### 2.1 LoRA权重选择
| LoRA类型 | 推荐权重 | 说明 |
|---|---|---|
| **杯型LoRA**（zodiac_thermos_v1） | 0.7~0.9 | 杯型结构LoRA，权重高一点锁形 |
| **材质LoRA**（ceramic/metal/matte） | 0.5~0.7 | 材质LoRA，权重太高会过饱和 |
| **风格LoRA**（minimal/vintage） | 0.4~0.6 | 风格LoRA，权重太高会盖过产品 |

### 2.2 多LoRA叠加配方
- **杯型+材质**：杯型LoRA(0.8) + 材质LoRA(0.6) = 结构准+材质对
- **杯型+风格**：杯型LoRA(0.8) + 风格LoRA(0.5) = 产品准+风格对
- **三个一起**：杯型(0.7) + 材质(0.5) + 风格(0.4) = 都要但都别太满

> 铁律：**LoRA总权重不要超过1.5**——加太多会互相打架，图会崩。

## 3. Prompt 工程规范

### 3.1 Prompt结构（正向词）
```
[质量词] + [主体描述] + [材质细节] + [场景/背景] + [光照] + [风格]
```

例子：
```
masterpiece, best quality, product photo,
stainless steel vacuum thermos, matte black finish, cylindrical shape,
on white background, studio lighting, soft shadow,
commercial photography, 8k, sharp focus
```

### 3.2 负向词（必须加）
```
low quality, blurry, deformed, ugly, extra parts, missing parts,
text, watermark, logo, cartoon, illustration, 3d render,
plastic texture, overexposed, underexposed
```

### 3.3 常见Prompt错误（避坑）
- ❌ 写太多抽象词（"beautiful, amazing, perfect"）——没用，AI不懂
- ❌ 写太多细节词——词太多会互相冲突，图会乱
- ❌ 用中文写Prompt——SDXL对英文支持最好
- ❌ 忘记加负向词——不加负向词，什么奇奇怪怪的都出来了

## 4. 判图标准与常见问题分类

### 4.1 什么叫好图（合格标准）
1. **结构对**：杯型/比例/结构和设计一致
2. **材质对**：金属/塑料/玻璃质感正确
3. **颜色对**：CMF颜色和设计一致
4. **背景对**：白底/场景符合要求
5. **无瑕疵**：没有多品/畸形/文字水印

### 4.2 常见问题分类与返修

| 问题类型 | 表现 | 原因 | 怎么改 |
|---|---|---|---|
| **多品** | 出现两个杯子 | Prompt太泛/ControlNet太弱 | 加ControlNet Depth/Prompt加"single cup" |
| **结构错** | 杯型变形/比例不对 | LoRA权重太低/Denoise太高 | 加杯型LoRA权重/降Denoise |
| **材质错** | 金属变塑料感 | CFG太高/材质LoRA没加 | 降CFG到5.5/加材质LoRA |
| **颜色错** | 颜色偏色 | 光照词不对/参考图不对 | 调光照词/换参考图 |
| **文字幻觉** | 杯身出现奇怪文字 | Prompt没禁文字 | 负向词加"text, watermark" |
| **背景乱** | 白底不干净 | Prompt没写清楚 | 正向词加"pure white background" |

## 5. 标准工作流模板

### 5.1 白底主图工作流
```
Checkpoint(SDXL) → LoRA(杯型0.8) → ControlNet Depth(0.8) 
→ KSampler(steps=32, cfg=5.5, sampler=dpmpp_sde+karras) 
→ VAE Decode → Save
```

### 5.2 场景图工作流
```
Checkpoint(SDXL) → LoRA(杯型0.7) → ControlNet Depth(0.7) 
→ IP-Adapter(场景参考0.6)
→ KSampler(steps=30, cfg=5.0, sampler=dpmpp_sde+karras) 
→ VAE Decode → Save
```

### 5.3 局部改色/改纹理工作流
```
[原图] → VAE Encode → Latent Mask(改的部位) 
→ KSampler(denoise=0.4, steps=25, cfg=5.0) 
→ VAE Decode → Save
```

## 6. 批量生产与成本

### 6.1 批量出图一致性
- 同一个产品出多张图：**固定seed+固定ControlNet**，只改Prompt里的背景词
- 不同角度：用同一个3D模型导出不同角度的Depth图，作为ControlNet输入

### 6.2 单图成本与效率（RTX 4090）
| 图类型 | 分辨率 | 单图时间 | 日产量（8小时） |
|---|---|---|---|
| 白底主图 | 1024×1024 | ~8秒 | ~3600张 |
| 场景图 | 1216×832 | ~12秒 | ~2400张 |
| 局部重绘 | 1024×1024 | ~5秒 | ~5700张 |

> 成本：RTX 4090电费约0.5元/小时，单图成本可忽略不计。瓶颈在Prompt调优和判图返修。

## 7. 铁律总结（必须记住）

1. **CFG 4.5–6.5，绝对不要上7+**——CFG>7就是塑料感，这是产品图的死穴
2. **Steps 28–36，不要堆到85**——步数太多没收益，反而慢
3. **产品图必须上ControlNet Depth**——没有ControlNet就是自由发挥，结构必错
4. **LoRA总权重≤1.5**——加太多会崩
5. **局部重绘Denoise≤0.55**——太高会改局部带坏整张
6. **负向词必须加**——不加负向词，什么奇怪东西都出来
