# memory/ · 记忆三层结构

> 治「失忆」= 三层，缺任一层等于没治。

| 层 | 位置 | 机制 | 闸值 |
|---|---|---|---|
| ① 可读真源 | `H:\架构\.workbuddy\memory\MEMORY.md` | 每轮注入 | **≤3980 字符**（超限被平台尾部截断 ⇒ 失忆） |
| ② 可检索载体 | `MEMORY_FACTS.md` + `_skill_router.md` + `_skill_index.json` | 按需检索 | 无上限 |
| ③ 常驻可见入口 | 工作台顶栏「整合包常驻速览」条（`fanallArchBar`） | 一眼可见 | 必含 |

## 关键事实

- 历史上最大规模 **19716 字符** ⇒ 直接注入会丢 **79.8%**（尾部全丢 ⇒ 表现为失忆）。
- 缺口由 `MEMORY_FACTS.md`（227 KB）承接，不受注入闸约束。
- 锚点**禁绑易变数字**（T97）：门禁通过数只做**格式匹配**，真值靠现跑判据取。
- 跨项目层另有一份：`~/.workbuddy/user-.../personal/MEMORY.md`（同样 ≤3980）。

## 判据

`_verify_memory_routing.py`（10 项）—— 门禁段23 接入；字符超限 / 锚点缺失 / 索引被归档污染 ⇒ 判红。
